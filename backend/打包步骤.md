命令

```shell
cd backend
pyinstaller ExamSystem.spec --clean --noconfirm
```

把 .env.example 复制到 dist/ 目录并重命名为 .env，或者让程序在启动时自动检测，没有就创建一份模板。

> ExamSystem/                         ← 打包发布目录
> ├── ExamSystem.exe                  ← 双击这个
> ├── .env                            ← 首次运行自动生成，>用户填写 MySQL 密码
> ├── db_config.json                  ← 首次在设置页保存后生成
> ├── ai_config.json                  ← 首次添加 AI Provider 后生成
> └── icon.ico                        ← 可选，仅打包时用
